MC Launcher API 文档

Base URL: http://localhost:9876/api。所有响应均为 JSON：{"ok":true,"data":...} 或 {"ok":false,"error":"..."}。

基础

方法端点说明
GET/ping健康检查
GET/info版本、数据目录、账号数量

版本

方法端点说明
GET/versions已安装版本列表
POST/versions/installbody: {"version":"1.20.1"}
POST/versions/removebody: {"version":"1.20.1"}
GET / POST/versions/verifyquery 或 body 传 version，校验 SHA1
POST/launchbody: {"version":"1.20.1","username":"Steve"}

账号

方法端点说明
GET/accounts返回 {accounts, current}
PUT/accountsbody: {"uuid":"..."} 切换当前账号
DELETE/accounts?uuid=...删除账号
POST/accounts/offlinebody: {"name":"Steve"}
POST/accounts/microsoft/start返回 userCode / verificationUri / deviceCode / interval / expiresIn
POST/accounts/microsoft/pollbody: {"deviceCode":"..."}，未授权返回 {"pending":true}，成功返回 {"pending":false,"account":{...}}

Java

方法端点说明
GET/java已检测到的 Java（path / major / version）
POST/java/installbody: {"major":17} 下载 Adoptium JRE
PUT/java/setbody: {"path":"/usr/bin/java"}

配置

方法端点说明
GET/config读取配置
PUT/config更新配置（maxMemory/minMemory/threads/width/height/javaPath/lang/source）

Modrinth

方法端点说明
GET/modrinth/search?q=&type=&offset=也兼容 page；返回 {hits, total_hits, offset, limit}
GET/modrinth/info/{slug}项目详情
GET/modrinth/versions?slug=&game_version=&loader=版本列表
POST/modrinth/installbody: {"slug":"...","type":"mods","game_version":"1.20.1","loader":"fabric"}

服务器列表

方法端点说明
GET/servers[{name, address}]
POST/serversbody: {"address":"mc.example.com","name":"示例"}
DELETE/servers/{address}按地址删除

示例

curl http://localhost:9876/api/versions

curl -X POST http://localhost:9876/api/versions/install \
  -H "Content-Type: application/json" \
  -d '{"version":"1.20.1"}'

curl -X POST http://localhost:9876/api/launch \
  -H "Content-Type: application/json" \
  -d '{"version":"1.20.1","username":"Steve"}'
