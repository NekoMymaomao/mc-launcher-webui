常见问题 FAQ

Q: 打开 http://localhost:9876 是 404 或只有 JSON？

A: 服务没找到前端目录。用 -static /绝对路径/frontend 指定，或把 frontend/ 放在可执行文件旁边。

Q: 提示找不到 Java？

A: 先执行 mc-launcher java list 看有没有检测到；没有就执行 mc-launcher java install 17 下载 Temurin JRE，或在设置里手动填 Java 路径。

Q: Java 版本不对导致启动失败？

A: 启动器会按版本 JSON 的 javaVersion.majorVersion 自动挑 Java。1.17+ 需要 Java 17，1.20.5+ 需要 Java 21，老版本需要 Java 8。

Q: 安装卡住或某些文件失败？

A: 安装结束会提示失败文件数。可以调大设置里的下载线程、换下载源，或重试一次（已下载且 SHA1 正确的文件会跳过）。

Q: 微软登录一直显示等待授权？

A: 需要在显示的验证地址里输入页面给出的代码并完成登录；设备码 15 分钟后过期，过期后重新点一次「Microsoft 登录」。

Q: 模组下载后不生效？

A: 启动器只是把文件下载到 mods/，不会安装 Forge/Fabric 这类加载器。模组要生效需要对应加载器环境。

Q: 支持 macOS / Android 吗？

A: 不支持，只维护 Linux 与 Windows。
